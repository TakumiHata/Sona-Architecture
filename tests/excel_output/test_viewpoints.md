# Excel出力テスト観点定義書

SonaCoreおよびSona-webにおけるExcel出力機能の品質を担保するためのテスト観点を定義します。

## 1. データ取得・変換 (SonaCore ↔ Sona-web)
SonaCoreから取得した議事録データが、正しくExcel出力用の中間フォーマット（Markdown）および最終的なExcelファイルへと変換されるかを検証します。

- [ ] **データの完全性**: 
    - 全てのセッション、発言、要約データが欠落なくExcelに含まれているか。
    - 長文の発言（1,000文字以上など）が途切れずに表示されているか。
- [ ] **型変換の正確性**: 
    - 日時データがExcelの正しい日付書式で出力されているか。
    - 数値(金額、件数など)が文字列ではなく数値型として扱われているか。
- [ ] **特殊文字の処理**: 
    - 改行コード、タブ、サロゲートペア（絵文字など）、HTMLタグ風の文字列がエスケープまたは適切に変換されているか。

## 2. マッピング・レイアウト (Excel Mapping Redesign)
`07_excel_mapping_redesign.md` で定義された「Markdown経由のマッピング」が意図通りに機能するかを検証します。

- [ ] **セルマッピング**: 
    - `$MeetingName`, `$Date` などのプレースホルダーが、対応するMarkdownデータの値で正しく置換されているか。
- [ ] **動的範囲の拡張**: 
    - 発言リストなどのリストデータにおいて、Excelの行がデータの数に応じて自動的に挿入・拡張されているか。
    - 拡張された際に、周辺のセルの書式や数式が壊れていないか。
- [ ] **シート出力制御**: 
    - 条件付きマッピングに基づき、特定の条件下でシートが生成される（またはスキップされる）か。

## 3. エッジケース・異常系
システムに負荷がかかる状況や、不規則なデータ入力に対する堅牢性を検証します。

- [ ] **大規模データ**: 
    - 数時間の長時間会議データを出力した際、メモリ不足やタイムアウトが発生しないか。
- [ ] **空データの処理**: 
    - 議事録が空（発言ゼロ）の状態で出力ボタンを押した際、エラーにならず適切な空ファイル（または警告）が出力されるか。
- [ ] **中断処理**: 
    - ファイル生成中にネットワークが切断されたり、ユーザーがブラウザを閉じたりした場合に、サーバー側のリソースが適切に解放されるか。

## 4. UI/UX・アクセシビリティ
ユーザーがExcel出力を利用する際の手触りや、出力後の利便性を検証します。

- [ ] **フィードバック**: 
    - 出力ボタン押下後、生成中であることを示すプログレスバーやスピナーが表示されるか。
- [ ] **ダウンロード体験**: 
    - 生成完了後、ブラウザで標準的なダウンロードダイアログが表示されるか。
    - ファイル名が「(会議名)_(日付).xlsx」などの期待通りの規則になっているか。
- [ ] **Excel上での可読性**: 
    - フォントサイズ、列幅の自動調整、折り返し設定などが、出力直後の状態で適切に設定されており、手動調整なしで読めるか。
